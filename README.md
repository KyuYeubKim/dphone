# D-Phone

BYD 돌핀(DiLink 3) 차량용 전화 앱입니다. BYD 기본 전화 앱은 화면 분할 칸에 들어가지 않아서,
분할 칸(좁은 칸부터 전체 화면까지)에 들어가는 전화 화면을 따로 만들었습니다.

- 키패드 / 최근 통화 / 연락처 / 통화 중 화면 (받기·끊기·음소거·통화 중 번호 누르기)
- 칸이 좁으면 탭으로 하나씩, 넓으면 목록과 키패드를 나란히
- 운전 중에도 누르기 쉬운 큰 버튼, 어두운 남색 화면
- 차에서 바로 확인할 수 있는 정보·진단 화면 (저장·공유)
- 앱 안에서 새 버전 확인·설치

휴대폰은 차와 블루투스로 연결되어 있어야 합니다. 통화 소리·운전대 버튼·계기판 표시는 지금처럼 BYD 전화 앱이 처리하고,
D-Phone 은 BYD 전화 앱이나 기본 전화 앱 설정을 바꾸지 않습니다.

## 설치
[Releases](https://github.com/KyuYeubKim/dphone/releases) 에서 `D-Phone-<버전>.apk` 를 받아 설치합니다.
처음 실행하면 전화·연락처·통화 기록 권한을 묻습니다.

시험판(Pre-release)은 개발 중인 버전입니다. 앱의 정보·진단 화면에서 버전 글자를 7번 누르면 시험판도 받는 '베타 채널'이 켜집니다.

이 앱은 개인이 만든 것으로 BYD 와 관계가 없습니다. 사용에 따른 책임은 사용자에게 있습니다.
